 # Medieval Run
 
Medieval Run is an endless runner set in a medieval world where survival depends on your ability to dodge obstacles and keep moving forward. Collect health and invincibility power-ups along the way to extend your run and survive for as long as possible.

With increasingly challenging gameplay and simple, fast-paced mechanics, Medieval Run turns each run into a test of timing, reflexes, and endurance.
 
 This is a game developed by a student from <a href="https://www.imagecampus.edu.ar/">Image Campus</a>
